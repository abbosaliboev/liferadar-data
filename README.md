# LifeRadar data

`events.json` — real events in Korea for the LifeRadar app, refreshed daily (06:00 KST) by GitHub Actions.

Sources (공공누리 open license):
- 서울 열린데이터광장 · 서울시 문화행사
- 한국관광공사 TourAPI · 축제·행사
- 창업진흥원 K-Startup · 사업공고

English titles, descriptions and interest tags are generated with Gemini; dates, places and prices come from the sources unchanged.
